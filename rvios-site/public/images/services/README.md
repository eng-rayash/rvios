# صور الخدمات

كل خدمة تقرأ خلفيتها من هنا باسم الـslug، وتُستخدم في بطاقة الخدمة (الرئيسية
وصفحة الخدمات) وفي رأس صفحة الخدمة نفسها. المسار مكتوب في حقل `image` داخل
`lib/services.ts`.

| الخدمة | الملف |
|---|---|
| تصميم المواقع | `web-design.webp` |
| تطوير المواقع | `web-development.webp` |
| أنظمة وتطبيقات الويب | `web-systems.webp` |
| المتاجر الإلكترونية | `ecommerce.webp` |
| صفحات الهبوط | `landing-pages.webp` |
| العناية بالموقع | `website-care.webp` |

## عند استبدال صورة

الأصول الخام (PNG) في `design-assets/services-source/` خارج `public` — أي ملف
داخل `public` يُنشر ويُحمَّل، والـPNG الأصلية ١.٥–٢ ميغابايت للواحدة، وخلفية
الرأس أول ما يُرسم في الصفحة (تضرب LCP مباشرة). المجلد مستثنى في `.gitignore`.

حوّل أي صورة جديدة قبل وضعها هنا:

```bash
node -e "require('sharp')('المصدر.png').resize({width:1600,withoutEnlargement:true}).webp({quality:80}).toFile('public/images/services/<slug>.webp')"
```

النتيجة المتوقَّعة ٥٠–٩٠ كيلوبايت بعرض 1600px (المجموعة الحالية ٤٠٥KB بعد أن
كانت ٩.٣MB). لتغيير الامتداد عدّل حقل `image` في `lib/services.ts`.

الصورة تُعرض تحت حاجب وتدرّج داكنين، فاختر صوراً بمساحات هادئة ولا تضع فيها
نصوصاً. وإن غاب الملف يظهر التدرّج وحده — لا صورة مكسورة.
